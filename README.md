# 🛋️ Farfale Living Georgia — Структура проекта и руководство

Сайт премиальной мягкой мебели индивидуального производства **Farfale** (Тбилиси, Ваке, ул. Н. Бердзенишвили 2).
Бренд: **Cool & Comfy | Style • Comfort • Durability | Custom-Made Sofas Crafted for Your Space**.

Сайт спроектирован с упором на **высокую скорость загрузки**, **локальное SEO для Google в Грузии** и модель **лидогенерации (заявка на расчет / WhatsApp / визит в шоурум)** без перегруженного интернет-магазина.

---

## 🛠️ Как редактировать контент

### 1. Изменить контакты, телефон, WhatsApp или адрес
Откройте **`data/site.json`**:
```json
"contacts": {
  "phone": "+995 555 12 34 56",
  "whatsapp": "https://wa.me/995555123456",
  "instagram": "https://www.instagram.com/farfale.ge",
  "address": "Vake, Tbilisi, N. Berdzenishvili 2"
}
```
*Данные автоматически обновятся во всех блоках сайта и кнопках связи.*

---

### 2. Добавить или изменить модель дивана
Откройте **`data/products.json`**:
Найдите нужную категорию (например, `modular` или `curved`) и добавьте/измените объект модели:
```json
{
  "id": "cloud-modular",
  "slug": "cloud",
  "title": "CLOUD LOUNGE",
  "category": "modular",
  "badge": "Бестселлер",
  "price_from_gel": 4200,
  "price_formatted_gel": "от 4 200 ₾",
  "lead_time": "от 25 дней",
  "description": "Описание модели...",
  "dimensions_standard": "Модули 105×105 см. Любые размеры под заказ.",
  "images": [
    "assets/images/products/cloud/cloud-01.webp",
    "assets/images/products/cloud/cloud-02.webp"
  ]
}
```

---

### 3. Добавить фотографии реализованного интерьера
1. Сохраните фото в формате `.webp` в папку `assets/images/portfolio/`.
2. Добавьте запись в **`data/portfolio.json`**:
```json
{
  "id": "project-07",
  "title": "Уютная гостиная в центре",
  "model": "Curve Organic в ткани Bouclé",
  "location": "Тбилиси, Ваке",
  "image": "assets/images/portfolio/interior-07.webp"
}
```

## 🚀 Оптимизация под Google (SEO в Грузии)

* **Семантическая микроразметка:** В `index.html` встроен `Schema.org/FurnitureStore` с точными координатами в Ваке (`41.7118, 44.7578`), графиком работы и диапазоном цен в лари (GEL).
* **Open Graph:** Превью для ссылок в WhatsApp, Telegram и Facebook подтягивает стильный постер с диваном и заголовком.
* **Производительность:** Все изображения сжаты в WebP (размер загрузки снижен с 28 МБ до ~15 МБ при сохранении максимальной четкости для экранов Retina).
* **Геотаргетинг:** Теги `<meta name="geo.region" content="GE">` и привязка к району Vake, Tbilisi.
