# 📸 Каталог изображений (Assets / Images)

Здесь хранятся все локальные изображения сайта, разбитые по смысловым папкам:

- **`hero/`** — Баннеры и фоновые изображения первого экрана главной страницы.
- **`products/`** — Фотографии моделей мебели.
  - Каждая модель в своей папке, например: `products/cosmo/01.webp`, `products/cosmo/02.webp`.
  - Пути к этим файлам указываются в `data/products.json`.
- **`showrooms/`** — Фотографии интерьеров шоурумов (Тбилиси, Дубай, Алматы, Москва).
  - Пути указываются в `data/showrooms.json`.
- **`blog/`** — Иллюстрации к статьям и анонсам мероприятий.
  - Пути указываются в `data/blog.json`.

> 💡 **Совет по формату:** Для быстрой загрузки сайта рекомендуем использовать формат `.webp` и оптимизировать размер фото (до 1600px по ширине для больших фото, до 800px для превью).
